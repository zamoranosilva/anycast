Descripción de la Aplicación

AnyCast es una solución de transmisión genérica de alto rendimiento diseñada para la reproducción fluida de contenido multimedia. La aplicación se especializa en la reproducción de formatos M3U8 y MP4, utilizando conectividad WebSocket avanzada y el protocolo STOMP para garantizar la sincronización en tiempo real y un control de baja latencia. Anycast es una utilidad completamente gratuita que no requiere registro de usuario, no contiene publicidad y no proporciona, aloja ni facilita ningún contenido o lista de reproducción predefinida, funcionando exclusivamente como un reproductor técnico para transmisiones proporcionadas por el usuario.

ACLARACIÓN DE SERVICIO:
Esta aplicación es una herramienta técnica "vacía". NO proporciona, NO aloja y NO facilita acceso a contenidos de video, servicios de streaming, listas de reproducción (M3U8) ni ningún tipo de suscripción multimedia.

Funcionalidades Técnicas:

  • Gratuidad Total: Aplicación de libre acceso, sin costos ocultos.
  • Arquitectura Privada: No requiere sistema de login, registro ni almacenamiento de datos de usuario.
  • Protocolo WebSocket: Receptor de archivos de manifiesto (m3u8) mediante comunicación de socket web en tiempo real.
  • Ejecución Efímera: La aplicación no almacena ni distribuye el contenido recibido tras finalizar la sesión de cast.

Guía de Integración Técnica (STOMP Protocol)

Para enviar contenido a AnyCast, utilice la url https://ws.sp33dforc3.com/cast-wss con el endpoint /inject-video, el siguiente es un ejemplo completo.

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>AnyCast - Emisor</title>
    <script src="https://cdnjs.cloudflare.com/ajax/libs/sockjs-client/1.5.1/sockjs.min.js"></script>
    <script src="https://cdnjs.cloudflare.com/ajax/libs/stomp.js/2.3.3/stomp.min.js"></script>
    <style>
        body { font-family: 'Segoe UI', sans-serif; display: flex; justify-content: center; padding: 50px; background: #f0f2f5; }
        .card { background: white; padding: 30px; border-radius: 12px; shadow: 0 4px 15px rgba(0,0,0,0.1); width: 400px; }
        input { width: 100%; padding: 12px; margin: 10px 0; border: 1px solid #ddd; border-radius: 6px; box-sizing: border-box; }
        button { width: 100%; padding: 12px; background: #007bff; color: white; border: none; border-radius: 6px; cursor: pointer; font-weight: bold; }
        button:hover { background: #0056b3; }
        #status { font-size: 12px; color: #666; margin-bottom: 15px; }
    </style>
</head>
<body>

<div class="card">
    <h2>Control de Cast</h2>
    <div id="status">Conectando al servidor...</div>
    
    <label>ID de la TV:</label>
    <input type="text" id="roomId" placeholder="Ej: ABC-123">
    
    <label>URL del Video (.m3u8):</label>
    <input type="text" id="videoUrl" value="https://demo.unified-streaming.com/k8s/features/stable/video/tears-of-steel/tears-of-steel.ism/.m3u8">
    
    <button onclick="enviarVideo()">Inyectar Video</button>
</div>

<script>
    var stompClient = null;
    var socketUrl = 'https://ws.sp33dforc3.com/cast-wss';

    function conectar() {
        var socket = new SockJS(socketUrl);
        stompClient = Stomp.over(socket);

        stompClient.connect({}, function (frame) {
            document.getElementById('status').innerText = "● Conectado al servidor";
            document.getElementById('status').style.color = "green";
            console.log('Conectado: ' + frame);
        }, function(error) {
            document.getElementById('status').innerText = "● Error de conexión";
            document.getElementById('status').style.color = "red";
        });
    }

    function enviarVideo() {
        var roomId = document.getElementById('roomId').value;
        var videoUrl = document.getElementById('videoUrl').value;
        var videoTitle = "Tears Of Steel";

        if (!roomId || !videoUrl) {
            alert("Por favor llena ambos campos");
            return;
        }

        var payload = {
            roomId: roomId,
            url: videoUrl,
            title: videoTitle
        };

        stompClient.send("/app/inject-video", {}, JSON.stringify(payload));
        console.log("Mensaje enviado a sala: " + roomId);
    }

    conectar();
</script>

</body>
</html>
